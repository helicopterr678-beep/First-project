# Number Guessing Game - Java

A simple Java console application where you play a guessing game against the computer.

## How to Play

1. Compile the program:
   ```bash
   javac GuessingGame.java
   ```

2. Run the program:
   ```bash
   java GuessingGame
   ```

3. The computer picks a random number between 1 and 100
4. You have to guess the number
5. After each guess, the computer tells you if your guess is too high or too low
6. Keep guessing until you find the correct number
7. The game shows you how many tries it took

## Example Game

```
Welcome to the Number Guessing Game!
I'm thinking of a number between 1 and 100.
Enter your guess: 50
Too high! Try a lower number.
Enter your guess: 25
Too low! Try a higher number.
Enter your guess: 37
Correct! You found it in 3 tries!
```
